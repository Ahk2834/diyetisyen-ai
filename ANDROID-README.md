## Diyetisyen AI Android test sürümü

Bu dal Capacitor ile Android debug APK oluşturur. GitHub Actions > Android APK (test) > başarılı çalıştırma > Artifacts bölümünden APK indirilir. Debug APK iki telefona kurulabilir. Android, bilinmeyen uygulama yükleme izni isteyebilir. APK'yı yalnızca kendi GitHub Actions çıktınızdan indirin.

**Gizlilik:** v0.4 sağlık profilleri tarayıcı localStorage alanında şifrelenmeden tutulur. Bu Android test sürümünde gerçek kişisel sağlık verilerini kaydetmeyin. Her telefonun yerel kayıtları ayrıdır; otomatik senkronizasyon yoktur.

**Güvenlik:** Klinik hastalıklar için bu uygulama tedavi diyeti oluşturmaz. APK henüz cihazda doğrulanmamıştır. Debug sürümü üretim dağıtımı için uygun değildir.
